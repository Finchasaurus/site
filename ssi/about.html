Why did I make Hoshiai.Space?

I wanted to learn about Web Development over the years and initially started with the traditional modern web stack with React and stuff.

I hated it.

React and CSS just do not go together at all, but Tailwind sucks, SASS sucks, it all sucks.

I ended up seeing this blog post linked on Twitter and decided to try out web development without all the frameworks and bloat.

Turns out web dev is actually fun when you ignore professional web developers and use modern html/css features

Now I just have fun doing stupid stuff and trying my best not to use JS
