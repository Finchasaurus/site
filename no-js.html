Navigating without JavaScript

This site is designed to work with as minimal JavaScript as possible. However, some features require JavaScript to function properly.

If you have JavaScript disabled, the core pages and content will still work properly, but some interactive features may not be available. You can still navigate through the site and access all the information, but certain dynamic elements may not function as intended.

To make user experience better, many features that require JavaScript are hidden when JavaScript is disabled, so you won't see any broken elements or non-functional features.

If you want to experience the full functionality of the site, please consider enabling JavaScript (I promise I'm not an evil tech bro trying to track you, I just want the site to work properly and look nice.)

Features that require JavaScript

  • Sidebar music player controls
  • The Currently section (Listening / Watching)
  • Automatic changelog updates in the sidebar

Alternative ways to access content

If you'd still like to follow site updates you can subscribe to the changelog RSS feed: here

All navigation is pure html and css and should still work. The sitemap provides an easy manner of navigation.

Why keep JavaScript optional?

I try to keep the site usable without JavaScript for a few reasons:

  • Some people disable it for privacy or security reasons
  • It can improve performance and reduce resource usage
  • It allows for a more stable and predictable experience across different browsers
  • It is a simple site that doesn't requite much complexity
  • It's just fun to solve problems with limited tools

My goal is progressive enhancement; JavaScript adds features but the site shouldn't depend on it when it doesn't need to.
